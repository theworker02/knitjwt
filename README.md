# knitjwt

Knit validation gates for jwt inputs before they hit prod.

**Site:** https://theworker02.github.io/knitjwt/

## Install / run

```bash
git clone https://github.com/theworker02/knitjwt.git
cd knitjwt
node src/cli.js
node --test
```
