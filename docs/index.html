Overview

Knit validation gates for jwt inputs before they hit prod. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/knitjwt.git
cd knitjwt
node src/cli.js --help
node --test
